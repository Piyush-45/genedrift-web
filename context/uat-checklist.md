# Genedrift website — review checklist

**September 2026 · www.genedrift.site**

A structured way through the site so nothing important gets missed. Please mark
each row and add a note where something is wrong — a note saying what you
expected is far more useful than "this looks off".

Two things to know before you start, because both look like faults and are not:

**After you publish a change in Creator, give it about a minute and refresh
twice.** Pages are cached for speed, so the first refresh can still show the
previous version.

**The site does not appear in Google.** That is deliberate while the content is
still placeholder. It is one setting to change when you are ready to launch.
